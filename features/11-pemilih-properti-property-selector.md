# Pemilih Properti (Property Selector)

Terletak di bagian paling atas halaman untuk memungkinkan pengunjung memilih properti kost yang ingin ditampilkan. Pada Fase 1 hanya tersedia satu properti default.

## Spesifikasi

### Tujuan
Memungkinkan pengunjung memilih properti kost yang ingin ditampilkan, diawali dengan satu properti default pada Fase 1.
### Selesai bila
- Pemilih properti terlihat di bagian paling atas halaman (header), menampilkan nama properti yang sedang aktif.
- Kontrol pemilih (dropdown) menampilkan satu opsi properti default, dengan desain yang bersih dan responsif.
- Teks dan ikon pada pemilih selaras dengan gaya premium keseluruhan situs.
- Dasar arsitektur komponen siap menampung beberapa properti tanpa perlu ubah struktur saat fitur diperluas.

## Task

### 1. Buat komponen header layout dengan data tiruan

### 2. Bangun komponen property selector dengan mock data

### 3. Integrasikan property selector ke header utama

### 4. Styling premium dan animasi dropdown halus

### 5. Pastikan responsivitas di semua perangkat

### 6. Tambah indikator visual untuk pilihan masa depan
